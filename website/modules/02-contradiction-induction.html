Day 2: Contradiction and Induction

A loop runs the same code again and again. Induction is the proof version of a loop: one argument covers infinitely many cases.

Read the claim, pick the outline

∃
There exists

Name one example and check that it works. For "a prime n ≥ 10," take n = 17.

∀
For all

"Let x be arbitrary." Assume nothing else about x, then show the property.

→
Implication

Direct proof: assume P and show Q. Or use the contrapositive: assume NOT Q and show NOT P.

¬
Contradiction

Proof by contradiction: assume NOT P, then break math. Example: √2 = a/b in lowest terms forces both a and b to be even.

Tip: You can write the skeleton of an "if and only if" proof before you understand the terms. Prove P → Q, then Q → P, and mark each gap with WTS ("want to show").

Induction as a bucket brigade

The first person gets a full bucket (the base case). Everyone passes it to the next person (the inductive step). The water reaches every person in line.

P(0)
P(1)
P(2)
P(n) …
💡
Key Insight: Induction trades infinitely many checks for two: one starting case, plus one step that works for an arbitrary n.

The tromino proof is an algorithm

tromino.py (inside tile) 
if size == 1:
    return
half = size // 2
mid_r, mid_c = top + half, left + half
for qr, qc in [(top, left), (top, mid_c), (mid_r, left), (mid_r, mid_c)]:
    if qr <= hole_r < qr + half and qc <= hole_c < qc + half:
        holes.append((qr, qc, hole_r, hole_c))
    else:
        r = mid_r - 1 if qr == top else mid_r
        c = mid_c - 1 if qc == left else mid_c
        board[r][c] = piece
        holes.append((qr, qc, r, c))
for qr, qc, hr, hc in holes:
    tile(board, qr, qc, half, hr, hc, counter)
Base case: a 1 × 1 board is just the hole, so there is nothing to place
Each quadrant is a board half as wide: 2ⁿ instead of 2ⁿ⁺¹
Find the centre, where the four quadrants meet
Visit the four quadrants one at a time
If this quadrant already contains the missing cell, keep that cell as its hole
Otherwise, pick the quadrant's corner cell that touches the centre
Cover it with this round's piece. The three covered cells together form one L
Now every quadrant is missing exactly one cell, the same problem at a smaller size
Inductive hypothesis: trust that each smaller board can be tiled, and recurse
⚠️
Common mistake: In the inductive step, n must be arbitrary. If your step only works for n = 3, you haven't proved P(n) → P(n + 1) for all n.

Principle of induction

← Tap to flip →

P(0) and ∀n (P(n) → P(n+1))

Together these give ∀n P(n). You prove the two pieces, and induction gives you everything else.

Why must a and b both be even in the √2 proof?

← Tap to flip →

a² = 2b²

So a² is even, which makes a even. Write a = 2c. Then b² = 2c², so b is even too. That contradicts lowest terms.
