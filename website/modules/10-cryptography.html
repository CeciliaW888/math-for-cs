Day 10: Cryptography

Every card payment you make crosses a network that strangers can tap. Today the number theory from the last two days turns into a lock that anyone can close but only one person can open.

Four ciphers, four ways to break them

1
Caesar cipher: shift by 3

There's no key at all, only a secret method. The day one general defects, every message can be read.

2
Caesar shift: shift by a secret k

There are only 26 keys, so Eve tries every one and keeps the output that reads like English.

3
Substitution: a random permutation

26! keys, but frequency analysis still cracks it: the most common symbol is probably E.

4
Enigma: the permutation changes every letter

This beats letter counting, but a known-plaintext attack using predictable weather reports broke it.

⚠️
Security by hubris: "I can't break it, so nobody can" is not a proof. Modern cryptography instead rests on problems the whole field of mathematics has failed to solve, such as factoring huge numbers.

A mail slot in Bob's door

In a public-key cryptosystem, Bob posts a public key that anyone can use to lock a message, and keeps a secret key for unlocking. It works like a mail slot: anyone can drop a letter in, but only Bob can open the box behind it.

RSA in eight lines of Python

toy_rsa.py 
from math import gcd
p, q, e = 11, 17, 7
n, phi = p * q, (p - 1) * (q - 1)
assert gcd(e, phi) == 1
d = pow(e, -1, phi)
c = pow(42, e, n)
print(n, d, c, pow(c, d, n))   # 187 23 15 42
print(all(pow(pow(m, e, n), d, n) == m for m in range(n)))
We need gcd to make sure our exponent is usable.
Two secret primes and a public exponent. Real keys use primes hundreds of digits long.
n is published. φ(n) = (p−1)(q−1) is never shown to anyone.
e must share no factor with φ(n), or it has no inverse.
The Pulverizer step: d is the inverse of e mod φ(n), here 23.
Encrypt 42 with three-argument pow, which never builds the huge number 42⁷.
Decrypting gives 42 back.
The proof says this works for every message, so we check all 187 of them: True.

Why decryption always works

1
Peel off one prime

(p−1) divides ed − 1, so ed = k(p−1) + 1 for some k.

2
Apply Fermat

m^(ed) = (m^(p−1))^k · m ≡ m (mod p). If p divides m, both sides are 0 anyway.

3
Repeat for q, then combine

p and q each divide m^(ed) − m, so their product n does too.

💡
Key Insight: Multiplying p·q is instant. Undoing it (factoring) is believed to be hopelessly slow. RSA hides the secret key behind that one-way street.

Split and recombine: the Chinese Remainder Theorem

The Chinese Remainder Theorem says: if x ≡ 4 (mod 5) and x ≡ 7 (mod 11), there is exactly one answer mod 55. List 7, 18, 29, 40, 51, and only 29 leaves remainder 4 when divided by 5.
