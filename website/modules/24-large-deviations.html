Day 24: Large Deviations: Chebyshev and Chernoff Bounds, Wrap Up

The average request takes 8 ms. How often can one take 16 ms or more? A tail bound answers questions like this without knowing the full distribution. The more you know, the stronger the promise.

Markov: averages limit extremes

If the average height in a room is 170 cm, half the room cannot be 340 cm giants. That is Markov's inequality: for R ≥ 0, Pr[R ≥ x] ≤ E[R]/x.

1
Split the average

E[R] = E[R | R ≥ x]·Pr[R ≥ x] + E[R | R < x]·Pr[R < x].

2
Bound each piece

The first conditional mean is at least x. The second is at least 0, because R is never negative.

3
Rearrange

E[R] ≥ x·Pr[R ≥ x], so Pr[R ≥ x] ≤ E[R]/x.

Direct

Scores in [30, 100], mean 75: Pr[R ≥ 90] ≤ 75/90 ≈ 83%.

Shift

R − 30 ≥ 0 has mean 45: Pr[R ≥ 90] ≤ 45/60 = 75%.

Flip

S = 100 − R ≥ 0 has mean 25: Pr[R ≤ 65] ≤ 25/35 = 5/7.

⚠️
Non-negativity is not optional: if R is ±1 with equal chance, E[R] = 0 and Markov would claim Pr[R ≥ 1/2] ≤ 0. Shift a variable up until it is non-negative before applying Markov.

Climbing the information ladder

📏 Markov
📐 Chebyshev
🚀 Chernoff
🎯 Exact
Chebyshev

Chebyshev's inequality: Pr[|R − E[R]| ≥ x] ≤ Var[R]/x². At least 2σ away: at most 1/4.

Chernoff

The Chernoff bound: Pr[R ≥ c·E[R]] ≤ e^(−β(c)·E[R]), β(c) = c ln c − c + 1.

Code ↔ English

tails.py 
import math
beta = 1.5 * math.log(1.5) - 1.5 + 1
for n in [20, 100, 400]:
    markov = (n / 2) / (3 * n / 4)
    chebyshev = (n / 4) / (n / 4) ** 2
    chernoff = math.exp(-beta * n / 2)
    print(n, markov, chebyshev, chernoff)  # n=20: Chebyshev wins; n=400: Chernoff wins
We need natural logs and exponentials for Chernoff.
β(3/2) ≈ 0.108: the constant for asking about 1.5 times the mean.
Try a small, a medium, and a large number of coin flips.
Markov uses only the mean n/2, so the bound never improves: 2/3.
Chebyshev uses the variance n/4 and a distance of n/4, giving 4/n.
Chernoff uses independence and shrinks exponentially in E[R] = n/2.
Constants matter for small n, but the exponential always wins eventually.
Lazy Susan, 5 phones

Markov says Pr[everyone matches] ≤ 1/5. The truth is exactly 1/5, so the bound is tight.

Shuffle, 5 phones

Same mean, same bound of 1/5. The truth is 1/120: Markov is 24 times too big, because it only sees the mean.
