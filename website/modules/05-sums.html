Day 5: Sums

A loop's running time is a sum of the cost of each pass. Today you learn to replace a long sum with a closed form, or, when none exists, to trap it between two easy numbers.

Four tools for four situations

🔁 Perturbation

Shift the sum a little, subtract, watch it cancel.

🎯 Ansatz

Guess the shape, solve for constants, then check.

🧮 Double sums

Work inside-out, or swap which index is outside.

📐 Integral method

No formula? Bound the sum with an integral.

The lottery prize

"$1 million" paid as $50,000 a year for 20 years is worth less than $1 million today. With interest rate p, a payment k years away is worth 1/(1+p)ᵏ now, so the prize is a geometric series.

💡
Frame difference: subtract two video frames taken a moment apart and everything that stood still disappears. Perturbation does the same to a sum.
1
Name it

S = 1 + x + x² + … + xⁿ⁻¹

2
Perturb it

xS = x + x² + … + xⁿ⁻¹ + xⁿ

3
Subtract

The middle cancels: S − xS = 1 − xⁿ

4
Solve and verify

S = (1 − xⁿ)/(1 − x). Then prove it by induction (guess and check).

annuity.py 
def annuity_closed(m, n, p):
    x = 1 / (1 + p)
    return m * (1 - x ** n) / (1 - x)

print(annuity_closed(50_000, 20, 0.0533))
# 638339.9...
print(1 / (1 - 1 / 1.0533))
# 19.76...
Price a stream of m dollars a year for n years at interest rate p.
x is what one dollar next year is worth today.
Apply the perturbation formula: one line, no loop, however big n is.
The "$1 million" prize is really worth about $638,000.
$1 a year forever: xⁿ shrinks to 0, leaving 1/(1 − x).
Getting paid forever is worth only about $20 today.

The ansatz: guess the shape

For Σ k² there is no obvious trick. But every term is at most n², and half of them are at least (n/2)², so the sum sits between about n³/8 and n³. An ansatz says: guess a cubic.

Guess: S(n) = an³ + bn² + cn + d. Four unknowns, so I need four facts.
S(0) = 0, S(1) = 1, S(2) = 5, S(3) = 14.
Solving the four equations: a = 1/3, b = 1/2, c = 1/6, d = 0.
Not proven yet! Sanity check n = 4: 64/3 + 8 + 4/6 = 30. And 1 + 4 + 9 + 16 = 30 ✓
Now prove it by induction. S(n) = n(n+1)(2n+1)/6.

Double sums: swap the order

In Σi=1..n Σj=i..n j, the pairs added obey 1 ≤ i ≤ j ≤ n. Exchanging the order of summation puts j outside: for each j, i runs 1..j, the inner sum is j·j = j², and the total is Σ j².

No formula? Use the integral method

ℹ️
Sharpen the bound: the integral method is off by at most one term. For Σ 1/i² it only gives 1 ≤ S ≤ 2, but adding the first three terms by hand narrows it to about 1.61 ≤ S ≤ 1.67 (true value 1.645).
