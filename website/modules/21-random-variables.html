Day 21: Random Variables

Programs rarely care about the raw outcome of a random process. They care about a number computed from it: packets lost, search time, hash collisions. Random variables are how we talk about those numbers.

💡
The barcode scanner: a random variable (RV) works like a scanner that deterministically reads a price off whatever basket you bring. The randomness lives in which basket you end up with, not in the scanner. Formally, R : S → ℝ.

Indicators, events and independence

An indicator takes only the values 0 and 1. Each event A gives an indicator 𝟙A, and each RV gives events such as [f = x], [f ≥ x] and [f ∈ T]. Two RVs are independent if the product rule holds for every pair of values.

coin_rvs.py 
space = list(product("HT", repeat=3))
f = lambda w: w.count("H")
g = lambda w: 1 if w[0] == "H" else 0
h = lambda w: 1 if len(set(w)) == 1 else 0
print("g, h independent?", independent(g, h))  # True
print("f, g independent?", independent(f, g))  # False
The sample space has 8 equally likely triples, from HHH to TTT.
f is just a function: give it an outcome and it returns the number of heads.
g is an indicator: 1 when the first flip is heads, otherwise 0.
h is an indicator: 1 when all three flips match.
The first flip says nothing about whether the other two match it, so g and h are independent.
If g = 0, then f cannot be 3, so learning g changes the odds for f.

Common distributions

B
Bernoulli(p)

An indicator: 1 with probability p and 0 with probability 1 − p.

U
Uniform on {1, …, n}

Each value has probability 1/n. The CDF is a staircase that climbs 1/n at each integer.

Bin
Binomial(n, p)

The number of heads in n independent p-coins. The PMF is C(n, k) pk(1 − p)n−k: count the sequences, then multiply by the probability of each one.

ℹ️
Tails shrink exponentially: with 100 fair flips, Pr[exactly 50] ≈ 0.08 but Pr[exactly 25] ≈ 1.9 × 10−7. Stirling's formula shows the PMF decays like 2−(something)·n away from np. So "at most 24 heads" (about 9 × 10−8) is actually less likely than "exactly 25".

Beating 50-50: the candy boxes

Two boxes hold different numbers of candies, each between 0 and 10. You open one at random, then keep it or switch. You win if you end up with more. A randomized algorithm wins more than half the time, whatever the boxes hold:

1
Guess a threshold

Pick t uniformly from {1, …, 10}.

2
Apply it

Keep the opened box if it has at least t candies. Otherwise switch.

3
Good guess (chance ≥ 1/10)

If smaller < t ≤ larger, the threshold tells the two boxes apart, so you win for certain.

4
Bad guess

You always keep or always switch, so you win with probability ½. In total, Pr[win] ≥ 1/10 + ½ · 9/10 = 0.55.
