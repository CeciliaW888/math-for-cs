Day 23: Expectation and Variance

Your system has 130 moving parts. How likely is it that something breaks? And once you know the average outcome, how far from it should you expect to land? Today brings two bounds for failures and a second summary number: variance.

Will anything go wrong?

Expected count

N = number of events that happen. By linearity, E[N] = Σ Pr[Eᵢ]. No independence needed.

Union bound ≤

The union bound: Pr[at least one] ≤ E[N]. Always true, often loose.

Murphy's law ≥

For mutually independent events: Pr[at least one] ≥ 1 − e^(−E[N]).

Why Murphy's law holds

1
Flip to the complement

Compute Pr[no event happens], then subtract from 1.

2
Multiply, thanks to independence

Pr[none] = (1 − Pr[E₁])(1 − Pr[E₂])⋯(1 − Pr[Eₙ]).

3
Bound each factor

1 − x ≤ e^(−x), so each factor is at most e^(−Pr[Eᵢ]).

4
Add the exponents

Pr[none] ≤ e^(−E[N]), so Pr[at least one] ≥ 1 − e^(−E[N]).

≈ 1 in 10⁶
130 parts at 90%: whole run works
73%
130 parts at 99%: something fails
12%
130 parts at 99.9%: something fails
⚠️
Independence matters: Lazy Susan phones have E[N] = 1, yet the chance anyone matches is only 1/n, far below 63%. The events are identical, so Murphy's law does not apply.

Code ↔ English

bounds.py 
import math
def compare(n, p):
    union = min(1, n * p)
    murphy = 1 - math.exp(-n * p)
    exact = 1 - (1 - p) ** n
    print(murphy, exact, union)
compare(130, 0.01)  # 0.727 <= 0.729 <= 1
We need e^x for the Murphy lower bound.
Take n independent parts, each failing with probability p.
Union bound: the expected count np, capped at 1 since nothing beats certainty.
Murphy: 1 − e^(−E[N]), trustworthy only because the parts are independent.
Exact answer: 1 minus the chance that all n parts survive.
Show the squeeze: lower ≤ exact ≤ upper.
A 130-part machine at 99% per part fails about 73% of the time.

Multiply yes, divide no

Independent product

E[D₁·D₂] = 3.5 × 3.5 = 12.25 for two independent dice.

Not independent

E[D₁·D₁] = E[D₁²] = 91/6 ≈ 15.17. Same die, so the rule fails.

Never divide

A takes 1 s and 2 s, B takes 2 s and 1 s. E[A/B] = E[B/A] = 1.25, so each looks slower than the other.

Variance: how wide is the scatter?

Two archers both average the bullseye. One cluster is tight, one is wild. Same mean, very different standard deviation.

Shift

Var[X + c] = Var[X]

Scale

Var[cX] = c² Var[X]

Shortcut

Var[X] = E[X²] − E[X]². Indicator: p(1 − p)

Independent sum

Var[X + Y] = Var[X] + Var[Y]. n coins: np(1 − p)

💡
Key Insight: Linearity of expectation never needs independence. Additivity of variance does. That is why diversification only helps when the risks are not tied together.

Plain deviations cancel

E[X − E[X]] is always 0. Squaring treats both sides alike and weights big misses more.
