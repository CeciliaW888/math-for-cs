Day 4: State Machines

Programs change over time, so two questions always matter: is the answer right? and does it ever stop? A state machine lets you prove both.

The parts of a machine

States Q

Everything the machine can remember. For the 8-puzzle: all 9! grids.

Start q₀

Where every execution begins.

Transitions q → r

The legal moves. Slide one neighbouring tile into the blank.

A state is reachable if some execution ends there. Our goal: prove that the solved grid is not reachable from the grid with 5 and 6 swapped.

Preserved vs. invariant

💡
Bishop rule: every bishop move stays on the same square colour. That property is preserved, so a light-square bishop never reaches a dark square. Impossibility proofs all work this way.

An invariant is true in every reachable state. The Invariant Principle connects the two:

1
Check the start

Show P(q₀) is true. This is the base case.

2
Check every move

Take any transition q → r, assume P(q), prove P(r). This is the induction step.

3
Conclude

P holds in every reachable state. Any state where P is false is unreachable.

ℹ️
Induction in disguise: apply the Invariant Principle to the counter machine 0 → 1 → 2 → … and you get the ordinary induction axiom back exactly.

The 8-puzzle proof, as a conversation

I keep getting 1 2 3 4 6 5 7 8. So close! Is it hopeless?
Read the tiles row by row and count inverted pairs. You have exactly 1: the 6 before the 5. Solved has 0.
A sideways move keeps the reading order the same. Count unchanged.
An up or down move hops one tile over two others: two neighbour swaps, each changing the count by plus or minus 1. Total change: even.
So odd stays odd forever. You start odd, the goal is even (0). Proven impossible.

Does it stop? Derived variables

Swap sort: while some neighbours are out of order, swap them. Its final states are exactly the sorted lists, so it is partially correct. To prove it halts, find a derived variable that is a natural number and drops on every move.

swap_sort.py 
def swap_sort(a):
    a, swaps = list(a), 0
    while bad := [i for i in range(len(a) - 1) if a[i] > a[i + 1]]:
        i = random.choice(bad)
        before = inversions(a)
        a[i], a[i + 1] = a[i + 1], a[i]
        assert inversions(a) == before - 1
        swaps += 1
    return a, swaps
Start counting swaps from zero.
Keep going while any neighbour pair is out of order. When none is, we are in a final state: sorted.
Pick any legal swap. The machine is allowed to choose, so the proof must work for every choice.
Remember the derived variable before the move.
Make the transition.
Check the key fact: each swap removes exactly one inversion.
So the loop runs exactly as many times as there were inversions, a finite number.
