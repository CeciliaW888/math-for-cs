Day 22: Expectation

How many tries until a randomized algorithm succeeds? How many hearts land in a random hand? A random variable holds a whole table of answers. The expectation boils it down to one number: the long-run average.

Definition

E[X] = Σ Pr[ω] · X(ω). A fair die gives (1+…+6)/6 = 3.5, a value the die never shows.

Indicator shortcut

For an indicator variable I of event A, the zeros vanish: E[I] = Pr[A].

Tail sums

For natural-number X: E[X] = Σ Pr[X > i]. Perfect for waiting times.

Mean time to failure

Flip a coin with Pr[heads] = p until the first head. The waiting time F follows the geometric distribution.

1
Spot the tail event

F > i means the first i flips were all tails.

2
Use independence

Pr[F > i] = (1 − p)^i by the product rule.

3
Sum the geometric series

Σ (1 − p)^i = 1 / (1 − (1 − p)) = 1/p. A fair coin needs 2 flips on average.

Linearity: the superpower

Linearity of expectation says E[X + Y] = E[X] + E[Y], always. Split a hard count into simple 0/1 pieces, then add.

💡
Key Insight: The product rule needs independence and the sum rule needs disjoint events. Linearity needs neither. Two dice glued together still average 7.
The school returned 30 phones at random. How many kids get their own phone back?
Counting all 30! shuffles sounds awful. Let me give each kid an indicator instead.
Kid k matches in (n−1)! of the n! shuffles, so the chance is 1/n.
Thirty indicators, each 1/30. Linearity says the expected count is exactly 1.
Fun twist: spin the phones on a Lazy Susan and the average is still 1, but now it is all or nothing.

Code ↔ English

hearts.py 
from fractions import Fraction
from itertools import combinations
deck = [(r, s) for r in range(13) for s in "SHDC"]
hands = list(combinations(deck, 3))
total = sum(sum(c[1] == "H" for c in h) for h in hands)
print(Fraction(total, len(hands)))  # 3/4
print(13 * Fraction(3, 52))         # 3/4
Use exact fractions so the two answers can be compared with no rounding.
We need every possible 3-card hand to apply the definition directly.
Build a 52-card deck as (rank, suit) pairs.
All 22,100 hands are equally likely, which is what makes a plain average correct.
Count hearts in every hand and add them up: the slow, brute-force road.
Divide by the number of hands to get the expectation: 3/4.
The fast road: 13 heart indicators, each with probability 3/52. Same 3/4.
⚠️
Common mistake: Do not write "X = Σ Pr[event]". X is a random variable and a probability is a number. Write X = Σ Iₖ first, then take expectations.
