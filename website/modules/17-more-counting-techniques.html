coprime_pie.py 
def coprime_pie(n, primes):
    total = 0
    for size in range(len(primes) + 1):
        for subset in combinations(primes, size):
            total += (-1) ** size * (n // prod(subset))
    return total

print(coprime_pie(30, [2, 3, 5]))  # 8
Count the numbers 1…n that share no prime factor with n.
Walk through subsets of the primes by size: 0, then 1, then 2, and so on.
n // (product) counts the multiples of every prime in the subset.
Even-size subsets are added and odd-size ones subtracted. The empty subset contributes all n numbers.
For 30 we get 8, which is Euler's totient φ(30) = 1·2·4.

Pigeonhole: name the three ingredients

The generalized pigeonhole principle says |A| > k·|B| forces a box with k + 1 items. The hard part is choosing the boxes. Here it is for 33 rooks on a chessboard:

1
Pigeons: the 33 rooks

We want 5 that share no row or column.

2
Holes: 8 wrap-around diagonals

Diagonal i is every square with (column − row) mod 8 = i. Each one meets every row and column once.

3
Map: rook → its diagonal

Every rook lies on exactly one diagonal, so the map is total.

4
Count: 33 > 4 · 8

Some diagonal holds 5 rooks, and those 5 never share a row or column.

ℹ️
Good to know: Pigeonhole proofs are non-constructive. Boston has more than 3 × 200,000 people, so at least 4 share a hair count, but the proof never says who.

Double counting Pascal's identity

I want to show C(n, k) = C(n−1, k−1) + C(n−1, k) without any factorial algebra.
Then count one set two ways. Take all length-n binary strings with exactly k ones.
Way 1: choose which k positions hold the ones. That is C(n, k).
Way 2: split on the last bit. If it ends in 1, place k−1 ones in n−1 spots, which is C(n−1, k−1). If it ends in 0, place all k ones in n−1 spots, which is C(n−1, k).
The two cases are disjoint and cover everything, so they add up to the same set. The identity is proved ✅

That identity is the rule that builds Pascal's triangle, and each row sums to 2ⁿ. The binomial theorem is the same counting story: in (x + y)ⁿ, the term xᵏyⁿ⁻ᵏ shows up once for each way to pick which k factors give an x.
