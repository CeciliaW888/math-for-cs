Day 13 · Connectivity and Trees

Can you get from here to there? Can you trace every street exactly once? Today's tools answer both questions by counting, so you never have to search through routes.

Walks, paths, cycles

A walk may wander and repeat itself. A path never repeats anything. A cycle is a closed loop with no repeats, apart from ending where it began.

1
Take a shortest walk from u to v

At least one walk exists, and lengths can't go below 0, so a shortest one exists.

2
Suppose it repeats a vertex

Say vi = vj with i < j. The stretch between those two visits is a detour.

3
Cut the detour out

Jumping from vi straight to vj+1 gives a shorter walk between the same endpoints. That contradicts "shortest".

4
So the shortest walk is a path

For questions about connectivity, "walk" and "path" are interchangeable.

Connectivity splits any graph into connected components. The 8-puzzle has two of them, one for even and one for odd permutations.

Euler: every edge exactly once

Picture a snowplow that must clear every street exactly once and come back to the depot. That route is an Euler tour. If it doesn't need to return, the route is an Euler walk.

💡
The theorem: a graph has an Euler tour exactly when it is connected and every degree is even. Each pass through a vertex uses one edge in and one edge out, so the edges get used up in pairs.
euler_status.py 

from collections import Counter
def euler_status(edges):
    deg = Counter(v for e in edges for v in e)
    odd = sorted(v for v in deg if deg[v] % 2 == 1)
    # assumes the graph is connected; the theorem needs that too
    if not odd:
        return "Euler tour"
    if len(odd) == 2:
        return f"Euler walk {odd[0]} to {odd[1]}"
    return f"neither ({len(odd)} odd vertices)"
We only need a counting tool. No route search is required.
Each edge adds 1 to the degree of both of its endpoints.
The odd-degree vertices are the only thing that matters.
Connectivity is the theorem's other condition, so check it separately.
No odd vertices means you can loop back to the start.
Exactly two odd vertices are the forced start and finish.
Four or more odd vertices means no single stroke can cover every edge.
ℹ️
Reduction trick: to prove the Euler walk case, add a new vertex x joined to the two odd vertices. Every degree is now even, so an Euler tour exists. Delete x again and the tour becomes the walk. You've turned a new problem into one you've already solved.

Trees and leaf pruning

A tree is connected and has no cycles. Every tree with at least two vertices has at least two leaves, namely the two ends of a longest path. Snip off a leaf and what remains is still a tree, so induction on trees almost always starts by pruning a leaf.
