Day 6: Asymptotics

Is n²/2 − n/2 steps better or worse than n log₂ n − n + 1? For a million items, the small terms don't matter. Asymptotic notation lets you drop that detail precisely, knowing exactly what you dropped.

Leaning blocks off a table

Stack n blocks, each sliding out as far as it can. The gaps are ½, ¼, ⅙, …, 1/(2n), so the overhang is ½Hₙ, where Hₙ is the harmonic number.

1
Integral method

1/x is decreasing, so ln n + 1/n ≤ Hₙ ≤ ln n + 1.

2
Divide by ln n

1 + 1/(n ln n) ≤ Hₙ/ln n ≤ 1 + 1/ln n.

3
Squeeze

Both sides tend to 1, so Hₙ/ln n → 1: Hₙ is asymptotically equivalent to ln n.

4
Reality check

Overhang of 10 block-lengths needs Hₙ = 20: hundreds of millions of blocks.

ℹ️
Products become sums: ln(n!) = ln 1 + … + ln n, so the integral method bounds n! within a factor of n. Stirling's formula is much sharper: n! ~ √(2πn)(n/e)ⁿ.

Big O: zoom out on the map

From orbit, side streets vanish and only the coastline remains. Big O does the same: f ∈ O(g) if some constant C and starting point n₀ make f(n) ≤ C·g(n) for all n ≥ n₀.

ratios.py 
import math

def swaps(n):
    return n * (n - 1) // 2

def merges(n):
    return n * math.log2(n) - n + 1

for n in (10, 100, 10_000):
    print(n, swaps(n) / n**2, merges(n) / swaps(n))
# ratios: 0.45 / 0.54, then 0.495 / 0.11, then 0.49995 / 0.0025
We need log base 2 for merge sort's bound.
Swap sort's worst case: every one of the n(n−1)/2 pairs is inverted.

The limit test, in conversation

Is n² in O(1,000,000 · n)? The constant is huge.
Take the limit: n² / (10⁶ n) = n / 10⁶, which goes to infinity. So no.
And 3ⁿ versus 2ⁿ? Isn't the base just a constant?
3ⁿ / 2ⁿ = 1.5ⁿ, which also goes to infinity. That is a constant multiplied n times, not once.
Rule: limit is infinite means not big O. Limit finite means big O. No limit means the test is silent.

The whole family

f ~ g

f/g → 1. Equal except lower-order terms.

O and Ω

f ≤ g, or f ≥ g, up to a constant factor.

Θ

Both O and Ω. n²/2 − n/2 ∈ Θ(n²).

o and ω

f/g → 0, or f/g → ∞. Much smaller, or much bigger.

⚠️
Never induct on big O: a "proof" that 2ⁿ ∈ O(1) goes 2ⁿ⁺¹ = 2ⁿ + 2ⁿ ∈ O(1) + O(1) = O(1). It only shows each single number 2ⁿ is a constant. Big O is a claim about the whole function at once.
