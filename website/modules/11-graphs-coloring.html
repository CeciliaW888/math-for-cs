Day 11: Graphs and Coloring

Friendships, server links, neurons, and exam clashes are all made of things plus pairs of related things. One abstraction covers them all, and it comes with theorems you can use straight away.

The vocabulary in one picture

A simple graph G = (V, E) has dots (vertices) and lines (edges). The degree of a vertex is how many edges touch it.

ℹ️
Two-way only today: Facebook friendships fit this model. Twitter follows and web links are one-way, so they need directed graphs, which come later in the course.

The handshake lemma

1
Count endpoints

Adding up all the degrees counts every end of every edge once.

2
Each edge has two ends

So the total is Σ deg(v) = 2|E|, which is always even.

3
Use it

Degrees 2, 2, 2, 2, 2, 1 add up to 11, which is odd, so no such graph exists. Also |E| ≤ n(n−1)/2, and the complete graph Kₙ reaches it.

4
Bipartite twist

Each side's degrees add up to |E|. So (average Harvard friends per MIT student) ÷ (average MIT friends per Harvard student) = |H|/|M| ≈ 1.6, whoever is friends with whom.

greedy_coloring.py 
def greedy(order):
    color = {}
    for v in order:
        taken = {color[u] for u in nbrs[v] if u in color}
        color[v] = min(c for c in range(1, 8) if c not in taken)
    return max(color.values())

print(greedy([0,1,2,3,4,5]), greedy([1,4,2,5,0,3]))  # 2 4
Greedy coloring takes an ordering of the vertices as its input.
The color assignments made so far start out empty.
Visit the vertices one at a time, in the given order.
Only neighbors that already have a color can block one. Later vertices are ignored for now.
Take the smallest color nobody nearby is using. That's why it's called greedy.
Report how many colors were needed.
Same graph (a 6-cycle plus one chord), two orders: 2 colors for one and 4 for the other. Order matters!

Coloring is conflict avoidance

A proper k-coloring keeps neighbors apart. The chromatic number χ(G) is the fewest colors that work. Think of seating feuding wedding guests at as few tables as possible.

Registrar here. I have 10 exam slots. Can someone just give me the best schedule? 🗓️
That's finding χ(G). Even deciding whether 3 colors are enough is NP-complete. No fast exact algorithm is known 😬
Then go greedy: fix an order and give each class the smallest free slot. It never creates a clash.
And if no class conflicts with more than d others, greedy uses at most d + 1 slots, in any order ✅
So the compiler folks do the same with registers, and radio engineers with frequencies? 📻
Exactly. Any time pairs can't share a resource, it's graph coloring.
💡
Key Insight: In the d + 1 proof, induct on the number of vertices, and start from an arbitrary (n+1)-vertex graph. Greedy colors the first n vertices as if the last one weren't there, and the last vertex has at most d blocked colors.
