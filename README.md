## About This Course

This course follows the 24 lectures of MIT OpenCourseWare's **6.1200J Mathematics for Computer Science** (Spring 2024, Prof. Erik Demaine, Dr. Zachary Abel, Dr. Brynmor Chapman), one lecture per day. Each day has a written study guide in plain language, Python snippets you can run to explore the ideas, exercises, a quiz and flashcards. The focus is intuition and the big ideas rather than formal rigor.

**Duration:** 24 days (4 weeks)
**Daily commitment:** ~1.5 hours (lecture video, optionally at 1.5x, plus the guide and exercises)
**Language:** English
**Level:** Some background (comfortable with algebra and basic programming; proofs are new)

## Learning Goals

By the end of this course, you will be able to:

- Read and follow mathematical proofs, and write simple ones using direct proof, contradiction and induction
- Reason about how fast sums and recurrences grow, using asymptotic (Big-O) notation
- Explain the number theory behind modular arithmetic and RSA cryptography
- Model problems with graphs: coloring, matching, trees and DAGs
- Count arrangements and selections with the core counting rules
- Use probability, conditional probability, expectation and variance to reason about uncertainty and randomized algorithms

## 🚀 Get Started

### Learn Online

Visit the course website (installable, works offline):

```
https://ceciliaw888.github.io/math-for-cs/
```

### Learn Locally

```bash
git clone https://github.com/CeciliaW888/math-for-cs.git
cd math-for-cs
# Read the guides in any markdown viewer, starting with:
#   week-01/day-01-predicates-sets-proofs.md
```

The website loads lessons with `fetch`, so open it through a local web server rather than double-clicking the file:

```bash
cd website
python -m http.server 8000
# then visit http://localhost:8000
```

### Install as PWA

1. Open the course website in Chrome or Edge
2. Click the "Install" icon in the address bar, or the **📲 Install App** button on the page
3. Open it from your desktop or home screen. Lessons you've opened work offline.
